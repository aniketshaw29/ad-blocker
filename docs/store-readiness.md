# Store Readiness - Chrome Web Store and Edge Add-ons

## Listing Information

- [ ] Final extension name and branding
- [ ] Short description accurately describes ad and tracker blocking
- [ ] Detailed description explains aggressive behavior and possible site breakage
- [ ] Privacy policy URL is public and uses the final contact address
- [ ] Support URL and issue-reporting process are available
- [ ] Changelog is prepared for the submitted version

## Required Assets

- [ ] Extension icon sizes prepared
- [ ] Store screenshots prepared for popup and core behavior
- [ ] Promotional images prepared if required
- [ ] Screenshots contain no misleading claims
- [ ] Assets are consistent across Chrome and Edge listings

## Technical Submission Review

- [ ] Version is incremented correctly
- [ ] Extension loads from the packaged archive
- [ ] No development-only files or secrets are packaged
- [ ] No remote executable code is included
- [ ] Permissions are documented and minimized
- [ ] Privacy policy matches implementation
- [ ] Public rule-list licenses/attribution are included where required
- [ ] Update endpoint and rule package are production-ready

## Claims to Avoid

- Do not claim that every advertisement or video ad will always be blocked.
- Do not claim zero breakage with aggressive blocking.
- Do not claim complete anonymity or protection beyond the extension's behavior.
- Do not describe telemetry as disabled unless verified in the packaged build.

## Submission Checklist

- [ ] Build production package
- [ ] Run `docs/qa-matrix.md`
- [ ] Complete `docs/security-review-checklist.md`
- [ ] Publish privacy policy
- [ ] Upload Chrome Web Store package
- [ ] Upload Edge Add-ons package
- [ ] Record submission IDs and review feedback
